BEGINNER FLOW

Step by step

Run these in order if you prefer to understand each stage instead of using the full wizard.

1

Hardware check

Detects your BC-250, dependencies and the board's real factory WGP map. It does not unlock hidden WGPs.

sudo ./bc250-unlock doctor
2

Stock baseline

Verifies that the factory 24-CU configuration is correct before testing anything hidden.

sudo ./bc250-unlock baseline
3

Compute scan

Tests each disabled 2-CU WGP independently and restores stock between candidates.

sudo ./bc250-unlock scan
4

Visual desktop check

Activates one compute-PASS WGP at a time while you move the mouse, open menus and move windows. You tell the tool if you saw artifacts.

sudo ./bc250-unlock visual
5

Review results

Shows which WGPs passed compute, passed visual validation, or were rejected.

sudo ./bc250-unlock results
6

Combined validation

Enables only WGPs that passed both gates, runs a heavier verifier and asks for one final visual check.

sudo ./bc250-unlock apply
7

30-minute stability test

Longer combined compute test with temperature and kernel-fault monitoring. Use real games too before persistence.

sudo ./bc250-unlock soak 30
8

Optional boot persistence

Only after games and soak tests are clean. Saves this board's approved routing and restores it at boot. BIOS/firmware are not modified.

sudo ./bc250-unlock persist install
